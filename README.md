# 💌 Carta Interativa Animada

Uma **experiência visual e emocional** construída com **HTML, CSS e JavaScript**, simulando a abertura de uma carta dentro de um envelope animado.  
Cada clique revela páginas, animações suaves e um segredo final — tudo pensado para criar um clima íntimo e delicado.

---

## ✨ Demonstração

📬 Clique no envelope para abrir  
📄 Clique na carta para avançar as páginas  
❤️ Ao final, a carta se fecha e revela uma mensagem secreta  

> Ideal para cartas digitais, homenagens, convites especiais ou projetos criativos.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura da carta e do envelope  
- **CSS3** — Animações, efeitos de profundidade, camadas e transições  
- **JavaScript (Vanilla)** — Controle de estados, páginas e interações  

Sem bibliotecas externas. 100% puro.

---

## 🎨 Principais Recursos

- ✉️ Envelope com animação 3D e selo animado  
- 📜 Carta com múltiplas páginas navegáveis por clique, teclado ou controles na tela  
- 🌟 Fundo animado com partículas (“memórias”)  
- 💖 Selo final com animação de fechamento  
- 🔒 Mensagem secreta revelada ao final  
- 🎁 Encerramento definitivo, sem opção de releitura  
- 📱 Design responsivo para desktop e mobile, incluindo orientação horizontal  
- ♿ Suporte a foco, leitores de tela e redução de movimento

## ✏️ Personalização

Você pode facilmente adaptar o projeto:

✍️ Texto da carta → edite as páginas no HTML

🎨 Cores e atmosfera → ajuste os gradientes no CSS

💫 Quantidade de partículas → altere MEMORY_COUNT no JavaScript

💌 Mensagem secreta final → edite o elemento #secretMessage

Os textos atuais são apenas exemplos neutros. A estrutura pode ser personalizada
diretamente no HTML quando você quiser adaptar a carta para uma ocasião específica.
